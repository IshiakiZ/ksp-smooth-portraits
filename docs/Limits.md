# Limits

* Tried with one and two kerbals in stock pods and one kerbal outside, on the launch pad. Not yet with
  a full three-seat pod's three portraits at once, in the cockpit view, or with parts from other mods.
* The game still takes a picture of its own for each portrait every two seconds. It is left that
  way so that nothing of the game's has to be replaced or switched off for good.
* If a later version of the game keeps its portraits differently, the mod says so in the log and on its
  page, and leaves them to the game.
* **Windows and Linux:** it is plain C# and asks only the game itself for things (no shader, no library
  of its own), so it should work there as on a Mac; it has been run on a Mac only.
