# Settings

In the Keystone window (the keystone button on the toolbar, or the modifier key and K: Option-K on a Mac,
Alt-K elsewhere). Drag a slider, or click the box beside it, type a number and press Enter; while you are
typing there the game's own keys are held off.

![The mod's page](../src/SmoothPortraits/img/portraits-page.jpg)

| Setting | Installed as | |
| --- | --- | --- |
| Smooth portraits | on | off: the game draws the portraits itself again |
| At most | 60 a second | the most pictures each portrait gets in a second (never more than the game draws frames) |
| Share of a frame | 3 % | the most of each frame's time the portraits may take; more gives more pictures when several portraits are showing |
| Kerbals outside too | on | off leaves the portraits of kerbals outside the ship to the game |

The page also says what the mod is doing: how many portraits, how many pictures a second each is
getting, and what they are costing.
